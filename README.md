# DES AES RSA Encryption and Decryption

This project demonstrates encryption and decryption using three cryptographic algorithms:
- DES (Data Encryption Standard)
- AES (Advanced Encryption Standard)
- RSA (Rivest–Shamir–Adleman)

## Features

- Encrypt and decrypt data using DES
- Encrypt and decrypt data using AES
- Encrypt and decrypt data using RSA
- Simple command-line interface

## Requirements

- Python 3.14.6
- PyCryptodome
